# CoreML model packages

Place the complete converted model packages here:

- `unet_sdxs_512.mlpackage/`
- `taesd_encoder_512.mlpackage/`
- `taesd_decoder.mlpackage/`

Each package must contain its `Manifest.json` and `Data/com.apple.CoreML/` files. The large generated weights are excluded from this repository; obtain/convert them separately and observe the SDXS and TAESD model licenses.
